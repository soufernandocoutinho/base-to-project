Guia para franqueados da **NextGo** utilizarem a ferramenta **Sites IA**.

Este repositório reúne documentação, exemplos de prompts e boas práticas para **importar, editar e publicar sites com inteligência artificial**, servindo como base de apoio e referência para novos projetos.

---

## 🎯 Finalidade

- Ensinar a criar **landing pages profissionais** usando IA (ChatGPT) de forma padronizada.
- Oferecer um **prompt completo** que reúne estratégia, copy, design, programação e auditoria.
- Disponibilizar **prompts prontos** para criar páginas otimizadas para SEO.
- Servir como **ponto de partida** para novos projetos (este repositório é um template).

## ⚡ Início rápido

1. Leia o **[MANUAL.md](MANUAL.md)**.
2. Baixe o arquivo **[PROFISSIONAL_CRIADOR_DE_LANDPAGE_COMPLETO.txt](PROFISSIONAL_CRIADOR_DE_LANDPAGE_COMPLETO.txt)**.
3. Crie o projeto **CRIADOR DE LANDING PAGES** no ChatGPT e anexe o arquivo às fontes.
4. Envie o briefing do cliente e gere a página.
5. Rode o **MODO AUDITORIA CRO** antes de publicar.
6. Use o **[PROMPTS_SEO.md](PROMPTS_SEO.md)** para refinar o SEO e a estrutura do HTML.
